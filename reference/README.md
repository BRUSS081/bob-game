# Reference

Pixel art di riferimento per stile, palette e luce. **Non sono asset di gioco.**
Sono generate da `npm run reference` (`scripts/render-reference.ts`) con la palette master di `src/render/palette.ts`, ispirandosi alle concept art AI della fase 1.

- `00-palette.png`: i 32 colori della palette master (prime due righe) e, sotto, le rampe ambiente per alba, giorno, tramonto, notte, pioggia, temporale.
- `01-keyart.png`: scena a mezzogiorno, 480×270 ingrandita ×4. Mare aperto, niente terraferma: surfer, kitesurfer e wing foiler (foil sotto la tavola), boa, scoglio, gabbiani.
- `02-timeweather.png`: la stessa scena nelle 6 condizioni di luce/meteo, ottenute rimappando gli indici della stessa palette.
